欢迎来到我的个人博客！

这是一个使用 Hexo 搭建的静态博客网站。

## 关于博客

这个博客将分享：
- 技术笔记
- 学习心得
- 生活随想

## 开始使用

如果你也想搭建一个类似的博客，可以参考以下步骤：

1. 安装 Node.js
2. 安装 Hexo：`npm install -g hexo-cli`
3. 初始化博客：`hexo init my-blog`
4. 选择主题并配置
5. 部署到 GitHub Pages

祝你在博客之旅中收获满满！
